# Diseño del software

Paquetes 3.1 a 3.4 de la EDT. Versión 1.0 · 25/10/2026.

| Documento | Contenido |
|---|---|
| Arquitectura_del_Sistema | Contexto, estilo cliente-servidor de tres capas, componentes y despliegue |
| Arquitectura_del_Software | Vistas 4+1, capas de la API, MVVM, secuencias y contrato REST |
| Justificacion_Arquitectura_de_SW | Impulsores, escenarios de calidad, ADR-01 a ADR-08 y análisis de riesgos |
| Informe_Patrones_de_Diseno_Aplicados | Strategy, Chain of Responsibility, Adapter, Decorator, Facade, Observer, State, Repository |

| Diseno_del_SW_Interfaz_y_Modulos | Wireframes W01–W21 y módulos M1–M6 |

## Carpetas

- `wireframes/`: pantallas en SVG editable (se arrastran a Figma).
- `diagramas/`: fuentes Mermaid (`.mmd`) y su imagen PNG. Para editar un diagrama, cambie el `.mmd` y vuelva a generar la imagen en https://mermaid.live.
- `base-de-datos/`: script SQL para PostgreSQL 15 (Supabase).

Toda modificación entra por pull request.
